# Open-source contribution mode

Before changing an external project: read CONTRIBUTING and style rules, check license and contribution terms, review issues and discussions, fit scope. Contributions are focused patches with tests and benchmark evidence, explain problem/fix/trade-offs, disclose AI assistance where required, and are never pushed, commented or opened as PRs without explicit authorization. RACE is not added to an upstream project unless maintainers chose it. Details: `references/core/open-source-contribution.md` and `optimize/references/open-source-contribution.md`.
