# Regression checklist

- [ ] Run the full test suite and compare with baseline
- [ ] Add characterization tests for untested behavior you touch
- [ ] Check public API and file-format compatibility
- [ ] Check error paths, edge cases (empty, large, malformed input)
- [ ] Check accessibility and localization behavior where UI is touched
- [ ] Check offline, save/restore and sync behavior where relevant
- [ ] Disclose anything not tested
